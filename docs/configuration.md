# Конфигурация

[Русский](configuration.md) | [English](configuration.en.md)

Приложение создает рабочий `SshTunnelTray.json` рядом с исполняемым файлом. Этот файл локальный и не предназначен для GitHub.

Для документации и тестов используйте [SshTunnelTray.json.example](../samples/SshTunnelTray.json.example). В нем специально оставлены только обезличенные значения:

- `example.com` — пример SSH-сервера;
- `your-user` — пример логина;
- `C:\\Users\\YOUR_NAME\\.ssh\\id_ed25519` — placeholder пути к ключу;
- `password: null` — пароль не записывается в публичный пример;
- `127.0.0.1` и тестовые порты — локальные значения.

`authMode: 0` означает использование файла ключа. Реальную конфигурацию удобнее создавать через окно приложения, а не редактировать вручную.
Поле `checkAfterSave` означает автозапуск выбранного профиля после сохранения настроек. Существующее имя поля сохранено для обратной совместимости.

## Что хранится локально

- имя профиля, SSH-хост, логин и порты;
- путь к приватному ключу, но не сам ключ;
- зашифрованное локальное значение пароля, если выбран парольный режим;
- путь к `ssh.exe`;
- выбранный язык интерфейса: `ru` или `en`.

Ни одно из этих значений не должно появляться в публичном коммите или скриншоте.
