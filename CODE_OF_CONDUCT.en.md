# Code of Conduct

[Русский](CODE_OF_CONDUCT.md) | [English](CODE_OF_CONDUCT.en.md)

The project welcomes calm technical discussion, reproducible examples, and respectful treatment of participants.

Insults, harassment, discrimination, publishing another person’s personal data, and disclosure of working secrets are not acceptable. When discussing an issue, remove real addresses, logins, paths, keys, passwords, and logs from examples.

Report violations to the project owner through the private channel listed in the repository profile. Do not use public messages to report a potential leak.
